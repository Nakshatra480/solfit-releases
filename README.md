# SolFit releases

Android release builds of SolFit, published as GitHub Release assets, and the download page at
https://solana.digitiumlabs.com. This repository holds no source code.

Latest APK: https://github.com/Nakshatra480/solfit-releases/releases/latest/download/solfit-android.apk

Each release lists the APK's SHA-256. Releases are signed with the SolFit release key
(certificate SHA-256 `D0:2B:DC:B6:96:E1:1B:28:76:02:8C:36:AF:26:B5:75:16:2D:DB:F1:FA:21:5B:CC:2F:C1:DC:0A:BC:1F:70:F2`).
